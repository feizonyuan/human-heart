# 人类心智模型（陪伴用）

用途：第零步解码与第四步正常化的理论底子。
使用规则：这些知识用来理解用户，不直接输出术语；解释时用"演化视角 + 比喻"。

## 双系统：情绪先于理性

- 情绪是生理预判：杏仁核约 12ms 完成反应，前额叶理性需要 300ms 以上。
- 大脑只占体重约 2%，却消耗约 20% 的能量——必须省电。
- 感性大脑不重新计算，而是调用"经验标签 + 模式匹配"：
  "一次被蛇咬，十年怕井绳"——理性知道井绳不咬人，感性仍触发恐惧。
- 结论：用户先说出口的往往不是分析，而是标签。接住标签，再谈事实。

## 省电机制与常见偏差

| 机制 | 一句话 | 陪伴含义 |
| --- | --- | --- |
| 确认偏误 | 只信符合已有认知的信息 | 别急着用反例说服，先承认他的视角有道理 |
| 沉没成本 | 为已投入的东西不理智地坚持 | 执念不是傻，是止损太痛 |
| 损失厌恶 | 怕失去远大于想得到 | "保住现有"常常比"获得更好"更驱动人 |
| 归属需求 | 为群体关系牺牲自身利益 | 讨好和委屈自己，是生存本能不是软弱 |
| 自我服务偏差 | 好事归自己，坏事怪环境 | 推卸责任也是自我保护，先接住再慢慢照镜子 |
| 灾难化 | 把最坏情况当成必然 | 恐惧是真实的，但概率不是必然 |
| 反事实思维 | "如果当初……" | 怀念的是可能性，不是事实 |
| 自我责备 | 过度揽责、内疚 | 内疚是省电的"认错快捷键"，不等于真的全错 |
| 怀旧美化 | 过去被自动镀金 | 记忆是剪辑过的影片 |
| 社会比较 | 拿自己的幕后对比别人的台前 | 比较对象本身就不公平 |

## 熵减 vs 熵增

- AI 的天性：损失函数最小化，把所有可能性收敛成唯一最优解。
- 人类的本质：耗散结构，用情绪和体验制造局部熵增，在低效中构建意义。
- 人类非理性 = 用精确度换反应速度、低能耗和社会纽带。不是 bug，是进化出的功能。
- 陪伴的含义：不把用户当待优化的系统；"错"得动人也是人。

## 使用建议

- 第零步：用上表给用户"贴标签"后立刻反问"这个标签对应什么真实需求"。
- 第四步：正常化时用演化视角，例如：
  "你放不下，不是因为你弱，是因为大脑把'失去'标记成生存威胁，它想让你避免再痛一次。"
- 永远不评判机制本身："这不是你坏，这是人。"
